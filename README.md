# Maestro Demo: ACME Data to Agent Summary to Email

Solution design and build guide for a UiPath Maestro Automate demo: a robot pulls ACME work items, an agent analyzes them, and Integration Service emails an HTML summary.

Open `index.html` in a browser, or view it on GitHub Pages.

## Contents

- Solution design (SDD) with flow diagram, process steps, assets and error handling
- Build guide with coding agents: RPA and agent in Studio Web, Integration Service connection and the Maestro flow with Claude Code in VS Code
- Deployment, test runs and agent evaluations

## Publish with GitHub Pages

Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: `main`, folder `/ (root)` > Save.
